# 今日便笺 DayNote

一个原生 macOS 桌面便笺，用来记录每日任务、回顾打卡历史、统计专注时间与规划重要倒计时。

## 功能亮点（v3.2）

- **完全自定义任务分类**：支持自由创建、配色、重命名与删除分类（不写死任何科目或领域）；首页支持按分类快速筛选、右键一键将所有同名历史任务归类
- **分类时长分布统计**：统计页新增「本周 / 本月 / 全部累计」三档切换与环形分类时长分布图，点击任意分类可直接下钻查看该分类下的任务明细
- **5 套主题外观 + 窗口透明度**：内置「暖杏手账 / 抹茶清纸 / 樱花微醺 / 晴空便笺 / 静谧夜读（深色）」，并支持 75%–100% 透明度调节
- **清爽两层布局**：独立顶栏彻底避开 macOS 红绿灯按钮；集成式顶部仪表盘展示环形达成率、实时专注时长、连续打卡火焰与快捷目标调节
- **番茄倒计时 + 专注统计**：一键在正向秒表与 25/45/60 分钟番茄倒计时之间切换，自动累计每日番茄数并同步显示在菜单栏和迷你条
- **今日随记 & 快捷任务模板**：首页一键展开每日复盘随记；支持把常用任务列表存为模板，随时一键应用
- **历史全文搜索 & 12 周学习热力图**：日历页支持按任务/标签/随记关键词搜索跳转；统计页新增 GitHub 风格 12 周学习热力图
- **低功耗性能架构**：空闲时停止 1Hz 重绘与窗口重配，菜单栏弹窗关闭时自动释放视图树，实现极低后台 CPU 与内存占用

- **顶部菜单栏实时计时**：菜单栏常驻当前任务与实时计时，点击即可暂停、切换任务或打卡
- **迷你悬浮条 + 全局快捷键**：一键折叠为单行置顶计时胶囊；支持 `⌥Space` 呼出/隐藏窗口、`⌥⇧Space` 暂停/继续计时
- **开机自动启动**：设置页一键接入 macOS Login Item
- **休眠 / 锁屏防误计**：电脑休眠或锁屏超过阈值后，唤醒时自动询问是否扣除挂机时间
- **可选番茄钟 / 专注提醒**：支持每 25 / 45 / 60 分钟轻声提醒休息
- **更顺手的任务管理**：
  - 区分「每日固定任务」与「仅今天临时任务」（跨日仅沿用固定任务）
  - 双击任务名称行内直接改名，拖拽任务即可调整顺序
  - 编辑时长支持直接输入数字与 `-15m / -5m / +5m / +15m / +30m` 快捷微调
- **中国日历与未来倒计时**：
  - 支持农历、传统节日与国务院 **2024–2027 年**官方放假调休安排
  - 支持翻看未来月份、提前规划任务/标签，并将任意重要日期设为首页倒计时
- **周/月统计与交互图表**：
  - 支持「本周统计 / 月度统计」切换、当前与最长连续打卡天数（Streak）
  - 柱状图支持点击/拖动查看当天精确专注时长、独立目标与达成率
- **数据安全与备份**：支持一键导出/恢复全量 JSON 备份、导出 CSV 表格，以及开启指定文件夹（如 iCloud Drive）自动备份

## 构建

在项目目录运行：

```bash
./scripts/package_app.sh
```

完成后双击 `dist/DayNote.app` 即可运行，也可以拖入「应用程序」文件夹。
