# 今日便笺 DayNote

一个原生 macOS 桌面便笺，用来记录每日任务、回顾打卡历史和统计专注时间。

## 功能

- 新增、勾选和删除每日任务
- 每项任务独立计时；开始新任务时会自动暂停上一项
- 关闭应用或重启电脑后仍可恢复数据和正在进行的计时
- 每一天独立保存任务、勾选状态和时长，跨日时自动沿用任务名称
- 日历显示有打卡/计时的日期，并可打开任意过去日期补记或修改
- 中国农历显示：每日农历日、农历月份和主要传统节日
- 内置国务院 2024–2026 年官方放假调休安排，以“休 / 班”区分
- 日期可添加多个彩色自定义标签，并支持编辑和删除
- 历史任务可修改名称、完成状态和小时/分钟时长
- 显示当天学习时长达成率、任务打卡数和总专注时间
- 每个日期拥有独立学习目标（未设置日期默认 8 小时），修改一天不会影响其他日期
- 首页直接显示当天目标，可用加减按钮按半小时调整，或点击时长使用快捷设置
- 达成率按“当天总学习时长 ÷ 当天目标”计算
- 月度统计按每天目标的总和计算，并用蓝色折线展示每日目标变化
- 悬浮置顶与桌面模式：桌面模式会把便笺固定在壁纸层并显示在所有桌面空间
- 所有数据仅保存在本机 `UserDefaults`

## 构建

在项目目录运行：

```bash
chmod +x scripts/package_app.sh
./scripts/package_app.sh
```

完成后双击 `dist/DayNote.app` 即可运行。也可以把它拖入“应用程序”文件夹。

## 使用

- 在底部输入任务，按回车添加。
- 点击任务左侧圆圈完成打卡。
- 点击右侧播放按钮开始计时，再次点击暂停。
- 右键点击任务可编辑名称、完成状态、时长或删除。
- 右上角日历按钮浏览历史，柱状图按钮查看月度统计。
- 显示器按钮切换桌面模式；桌面模式下便笺位于普通应用窗口之后，可通过“显示桌面”看到。
- 图钉控制普通窗口模式下是否始终置顶。

## 数据升级

2.0 会自动迁移 1.0 版已有任务和计时数据。历史档案使用新的 `daynote.saved-archive.v2` 本地存储键。

2.0.1 修复桌面模式下 Finder 桌面层截获鼠标事件、导致便笺无法点击和输入的问题。

2.1 将达成率从任务勾选比例改为学习总时长比例；任务勾选仅作为打卡记录。

2.2 新增中国农历、国务院法定节假日/调休标注和日期自定义标签。

2.3 学习目标改为按日期独立保存；月达成率按每天各自目标汇总计算。

2.3.1 将当天目标设置移到首页，提供直接可见的半小时加减控制和快捷选项。
